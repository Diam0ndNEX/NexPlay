# NexPlay

A personal iPhone game player for RPG Maker MV/MZ and HTML5 games.

- Import a game as a ZIP, a folder, or a single HTML file.
- Detects the engine, game title and cover automatically.
- On-screen controls, fast forward (RPG Maker), FPS/battery overlay, orientation lock.
- Per-game storage, save backup and restore.

Built by GitHub Actions as an unsigned IPA. Sign it with your own certificate.
